# QazRus Overlay

Android-приложение для распознавания казахского текста на экране и подготовки русского перевода поверх других приложений.

## Текущий статус

**Версия 0.1.0 — ранний прототип.**

Уже реализовано в исходном коде:
- Запрос системного разрешения Android на захват экрана через MediaProjection.
- Захват одного кадра после явного подтверждения пользователя.
- Локальное OCR через Tesseract4Android с языками `kaz+rus`.
- Загрузка языковых данных Tesseract при первом запуске OCR.
- Отображение распознанного текста или ошибки в основном окне и уведомлении.
- Отдельное разрешение Android на показ плавающей панели поверх других приложений.
- Закрываемая плавающая панель с результатом OCR (показывает оригинал, не перевод).

Пока НЕ реализовано:
- Автоматический перевод распознанного текста с казахского на русский.
- Постоянное распознавание в реальном времени.
- Плавающая панель пока показывает только распознанный оригинал, а не перевод.
- Настройки и оптимизация производительности.

## Сборка APK

GitHub Actions автоматически собирает debug APK при каждом push в ветку `main`, а также вручную через вкладку **Actions** → **Android debug APK** → **Run workflow**.

После успешной сборки открой запуск workflow и скачай artifact **QazRus-Overlay-debug**.

## Разрешения и ограничения

- Android должен явно запросить разрешение пользователя на захват экрана.
- Приложение не обходит защищённые окна, DRM или ограничения игр.
- Некоторые приложения и игры блокируют захват экрана.
- OCR обрабатывает изображение локально; языковые файлы скачиваются из репозитория Tesseract при первом использовании.
- Переводчик и overlay будут добавляться отдельно, с понятными настройками и системными разрешениями.

## Технологии

- Kotlin
- Android SDK 35
- MediaProjection API
- Tesseract4Android (`kaz` + `rus`)
- Gradle и GitHub Actions
