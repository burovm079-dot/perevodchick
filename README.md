# QazRus Overlay

Android-приложение для распознавания казахского текста на экране и показа русского перевода поверх других приложений.

## Текущий статус

**Версия 0.1.0 — стартовый каркас.** Сейчас приложение открывает стартовый экран. Захват экрана, OCR, перевод и плавающее окно ещё не реализованы.

## План разработки

1. Запросить разрешение Android на захват экрана через MediaProjection.
2. Распознавать казахский текст на изображении экрана. Для казахской кириллицы нужно выбрать и проверить OCR-движок с поддержкой кириллицы (например, Tesseract с языковыми данными kaz и rus).
3. Добавить казахско-русский переводчик. OCR и перевод — отдельные компоненты; ML Kit Text Recognition сам по себе не переводит текст.
4. Показывать перевод в разрешённом Android overlay-окне.
5. Добавить настройки частоты распознавания, размера текста и включения/выключения перевода.

## Сборка APK

GitHub Actions автоматически собирает debug APK при каждом push в ветку `main`, а также вручную через вкладку **Actions** → **Android debug APK** → **Run workflow**.

После успешной сборки открой запуск workflow и скачай artifact **QazRus-Overlay-debug**.

## Важно о приватности и разрешениях

- Android должен явно запросить разрешение пользователя на захват экрана.
- Приложение не должно обходить защищённые окна или ограничения игр.
- Для первой версии предпочтительна локальная обработка изображений. Не отправляй игровые скриншоты на сторонние серверы без явного согласия.
- Некоторые приложения и игры блокируют захват экрана или отображение поверх себя.
